# デモ映像の撮り方

Deskroid を自動で動かしながら、キャラのまわりだけを切り抜いて MP4（1280×720・30fps・音声つき）に録画する。
X などで宣伝するための映像用。

- `record.js`：録画する本体。Deskroid をデバッグポートから操作して、台本どおりに話しかける
- `recorder.html`：録画用の画面。左に説明の文字、右にキャラを並べて MP4 にする
- `check.js`：できた映像の確認用。16 か所の画面を 1 枚の画像（`contact.png`）にまとめ、音が入っているかも調べる

## 台本（約 73 秒）

| 時間 | 場面 | 話しかける言葉 |
|---|---|---|
| 0〜3 秒 | タイトル「デスクトップに住む、話せる相棒」 | — |
| 01 | 話しかけるだけ | 「はじめまして！自己紹介して」 |
| 02 | パソコンのことを手伝う | 「明日の東京の天気どう？」 |
| 03 | タイマー・リマインダー | 「8秒後にお茶が入ったって教えて」→ 8 秒後に ⏰ で知らせる |
| 04 | コピーした文章を翻訳・要約 | （英文をクリップボードに入れてから）「これ日本語に訳して」 |
| 最後 | リンクとクレジット | — |

台本や説明の文字は `record.js` の中の `say(...)` と `setState(...)` を書き換える。

## 撮り方

1. 公開して大丈夫なキャラにする（`assets/avatars/` の VRoid サンプル。いつもはヴィータ）。
   `config.local.json` の `activeCharacter` を `"vita"` にする（撮り終わったら戻す）
2. Deskroid をデバッグポート付きで起動する

   ```bash
   node_modules/electron/dist/electron.exe . --remote-debugging-port=9222
   ```

3. 声と会話の準備ができるまで待つ（VOICEVOX のエンジンと Ollama のモデルの読み込み）
4. マウスのカーソルを画面の左の方に置いておく（切り抜く範囲に入らないように）
5. 録画する（約 1 分半。そのあいだ画面は暗い背景で覆われるので触らない）

   ```bash
   node_modules/electron/dist/electron.exe scripts/demo/record.js
   ```

   保存先は「ビデオ」フォルダの `deskroid-demo.mp4`。変えるときは環境変数 `DEMO_OUT` にパスを入れる
6. 確認する（最後の数字は映像の長さの目安・秒）

   ```bash
   node_modules/electron/dist/electron.exe scripts/demo/check.js <動画のパス> 75
   ```

   同じ場所にできる `contact.png` を見て、キャラが最後まで映っているか、吹き出しの中身がおかしくないかを確かめる。
   返事は毎回 AI が作るので、気に入らなければ撮り直す

## 気をつけること

- **クレジット**：VOICEVOX の声を使った映像は「VOICEVOX:冥鳴ひまり」のような表記が必要（最後の画面に入れてある）。
  キャラや話者を変えたら、最後の画面のクレジットも変える
- **権利**：ゲームや作品由来のモデル（`models/` のもの）は宣伝に使わない
- **背景の幕はタスクバーを残す**：画面全体を覆うと Windows が「全画面アプリ」とみなし、最前面の Deskroid を下げてしまう
- **場面ごとに会話をリセットしている**：前の場面の会話が残っていると、前の頼みを返事に混ぜることがある
- **クリップボード**：翻訳の場面でクリップボードを書き換えるが、撮り終わったら元に戻す
- **形式**：Electron の録画機能で作った MP4（H.264 + AAC）。投稿先で弾かれたら、別のツールで保存し直す
